ATLAS Schema — 2026-12 current

Draft 2020-12 JSON Schemas for ATLAS model and dataset cards, plus three conformance profiles. See the changelog for what changed since 2025-11.

Schemas

  • model.json Schema for AI model cards: general metadata, model properties, performance reporting, integration, dataset linkage, and more.
  • dataset.json Schema for AI dataset cards: general metadata, dataset properties, imaging characteristics, partitions, and model linkage.

Conformance profiles

Each profile is an overlay over model.json that narrows which fields are required, without adding new properties. A card conforming to a profile still declares "$schema": "https://atlas.rsna.org/schemas/2026-12/model.json"; profile membership is computed by the registry at ingest.

  • profiles/minimal.json Identical to the base schema — only Name and Link are required.
  • profiles/procurement-ready.json What a buyer needs to evaluate fit: intended use/users, input/output, clinical risk level, at least one performance record with a test type, dataset linkage, and a regulatory-authorization record.
  • profiles/regulatory-ready.json Cumulative on procurement-ready: adds bias-mitigation approach, cybersecurity measures, predetermined change control, a maintenance plan, training-data provenance, and external-testing evidence.
