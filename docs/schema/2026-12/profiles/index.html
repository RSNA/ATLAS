ATLAS 2026-12 Conformance Profiles

Each profile overlays model.json via allOf, narrowing required/cardinality without adding new properties. A card conforming to a profile still declares "$schema": "https://atlas.rsna.org/schemas/2026-12/model.json".

  • minimal.json Identical to the base schema — only Name and Link are required.
  • procurement-ready.json What a buyer needs to evaluate fit.
  • regulatory-ready.json Cumulative on procurement-ready; adds regulatory-facing requirements.
See the changelog for what each profile requires and why.
