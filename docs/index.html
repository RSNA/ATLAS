RSNA ATLAS JSON Schemas

Machine-readable schemas for ATLAS model and dataset cards, aligned with the RSNA/ROADMAP ontology.

Versions

  • schema/2026-12/ current Model and dataset schemas, three conformance profiles (minimal, procurement-ready, regulatory-ready), and the changelog describing what changed since 2025-11.
  • schema/2025-11/ Prior version, kept for reference and for cards that still declare it.

About

ATLAS is RSNA's library of AI models and datasets. Each model or dataset is described by a JSON "card" conforming to one of the schemas above. The source for these schemas, and for the repository this site is published from, is github.com/RSNA/ATLAS.

For questions, contact RSNA's Informatics Department at informatics {AT} rsna {DOT} org.
